# II Digital Twins in Networking

> **Digital twins** copycat any feature they are based upon. In networking, we will see how tools like **Cisco Packet Tracer** and a **web-based virtual machine with Mikrotik RouterOS** can help you practice before working with real hardware.

### What is a Digital Twin?

<mark style="background-color:purple;">A</mark> <mark style="background-color:purple;"></mark><mark style="background-color:purple;">**digital twin**</mark> <mark style="background-color:purple;"></mark><mark style="background-color:purple;">is a</mark> <mark style="background-color:purple;"></mark><mark style="background-color:purple;">**virtual copy of a real system**</mark><mark style="background-color:purple;">.</mark>\
In networking, this means we can create a **virtual network** that behaves almost like a real one — with switches, routers, PCs, cables, and connections — but all simulated on a computer.

With a digital twin:

* You can **design, configure, and test** a network safely.
* You can **experiment** without breaking anything physical.
* You can **see how routers and switches react** to your configurations in real time.

Before we start working with real devices in the workshop, we’ll use two digital twin environments:

1. **Cisco Packet Tracer**
2. **A web-based virtual machine with Mikrotik RouterOS**

Let’s see what each one does and why we use them.

### Cisco Packet Tracer – Network Simulator

#### What It Is:

Cisco Packet Tracer is a **simulation program** developed by Cisco.\
It lets you **create virtual networks** using routers, switches, computers, servers, and more — all inside your computer.

#### What You Can Do:

* **Drag and drop** network devices and connect them with cables.
* **Configure routers and switches** using the same commands as on real Cisco devices (via the Command Line Interface – CLI).
* **Simulate data flow** to see if your configurations work (for example, testing pings, routing, VLANs, etc.).
* **Visualize** how information travels through the network using Packet Tracer’s animation tools.

#### Why We Use It:

* It’s **safe** — no risk of misconfiguring or damaging real hardware.
* It’s **portable** — you can install it on your laptop and practice anywhere.
* It’s a great **first step** to understand basic network concepts before working with real equipment.

***

### Web-Based Virtual Machine (Mikrotik RouterOS)

#### What It Is:

A **web-based virtual machine** is like having a **remote computer running in your browser**.\
In our case, it runs **Mikrotik RouterOS**, an operating system used in many real routers and network setups.

#### What You Can Do:

* **Access the Mikrotik command line or graphical interface (WinBox)** directly from your browser.
* **Configure interfaces, IP addresses, routing, and firewalls** as if you were working on a physical Mikrotik router.
* **Test and save your configurations** in a real OS environment that behaves just like actual network hardware.

#### Why We Use It:

* It gives you experience with **real router software**, not just a simulation.
* You can **experiment freely** in an isolated online environment.
* It prepares you to manage **Mikrotik-based networks** in the real world — a skill valued in many workplaces.

### Why This Order?

1. **Start safe:** Build confidence in virtual environments.
2. **Practice commands:** Learn how routers and switches “think.”
3. **Apply knowledge:** Use the same concepts on real hardware.

By the time you get to the workshop, you’ll already know **what to do and why**, so you can focus on **how to do it efficiently** with actual devices.

## Physical network diagram VS Logical network diagram

A logical network diagram is a visual representation of a network's high-level structure, showing how devices, subnets, and connections interact logically without detailing physical components or exact hardware locations.

# Advanced Network Configuration

{% hint style="info" %}
#### **A Note on Course Structure**

Please be aware that the subtopics covered in this section—specifically [**5.1 Wireless Communication**](#user-content-fn-1)[^1]**s** and [**5.2 Virtual LAN**](#user-content-fn-2)[^2]—were originally planned to be included under **Topic 3: Computer Network Configuration**. However, due to the specific timing and milestones of **CHALLENGE #2**, these subjects have been moved to this dedicated section to better facilitate the transition into **CHALLENGE #3**.
{% endhint %}

### **Course Summary**

Before diving into these advanced concepts, it is useful to recap the progress made in the previous stages:

* **Challenge #1 (Physical Layer):** This focused on **Topic 2:** **Deploying Ethernet cabling**. We explored networking features, physical topologies, and the assembly of hardware components, ensuring a solid physical foundation for connectivity.
* **Challenge #2 (Logical Layer):** We moved into **Topic 3: Computer Network Configuration**. During this phase, we mastered MAC and IP addressing, fixed-length subnetting, and the fundamentals of routing (filling routing tables and configuring gateways) to establish internet access.

#### Challenge #3

As we advance in the course, we will move beyond physical cables to add wireless access points and Virtual LANs to you local network deployments. In other words, this is your chance to show everything you learned so far in the previous challenges and will incorporate these last two advanced features.&#x20;

[^1]: Transitioning from fixed transmission media to flexible **WLAN** environments

[^2]: Mastering the logical segmentation of networks to improve security and optimize traffic flow.

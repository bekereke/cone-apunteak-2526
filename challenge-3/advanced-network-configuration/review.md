# Review

## Wireless Communications

1. Zein frekuentziatan egiten dute lan WiFi atzipen puntuek?
2. Zein WiFi bertsio daude? Zein da bertsio bakoitzaren frekuentzia? Eta abiadura?
3. Bateragarriak al dira frekuentzia ezberdinetan lan egiten duten gailuak?
4. Zer da WiFi kanal bat? Nola aukeratu dezakegu gure hari gabeko sarearentzat kanal egokiena
5. WiFi sarearen segurtasunari dagokionean, zein aukera ditugu (pasahitz motak…)? Azaldu bakoitzaren ezaugarriak.
6. Mugikorrean begiratu gure eskolako WiFi sareak zein kanaletan eta zein frekuentziatan dauden (Wifi Analyzer aplikazioa). Ipini pantaila argazki bat eta azaldu zure hitzekin irudian ikusten dena.

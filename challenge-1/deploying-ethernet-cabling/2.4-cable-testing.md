# 2.4 Cable testing

> A network tester is an important tool for technicians and network administrators. It is designed to assess the operational status of network connections, identifying issues in signal strength, interference, and connectivity.&#x20;

<figure><img src="https://images.unsplash.com/photo-1729549223893-b340db51e577?crop=entropy&#x26;cs=srgb&#x26;fm=jpg&#x26;ixid=M3wxOTcwMjR8MHwxfHNlYXJjaHwxfHxuZXR3b3JrJTIwdGVzdGVyfGVufDB8fHx8MTc1OTEzNTU0NHww&#x26;ixlib=rb-4.1.0&#x26;q=85" alt=""><figcaption></figcaption></figure>

This category encompasses a variety of testing tools, including network cable testers, Ethernet test devices, and more specialized equipment like cable network certifiers. These devices ensure that a network's cabling and connections are functioning optimally, which is essential for maintaining robust network performance.

Testing Ethernet cable is straightforward with the right tool. The procedure typically involves connecting the tester to the cable, transmitting a variety of signals, and reading the results to identify any connectivity or signal quality issues. This process helps pinpoint problems like breaks, short circuits, and crosstalk interference, and ensure the reliability of network connections.

### Continuity testing

Continuity testing is a simple process that can help you detect any faults or breaks in the cable that may be causing connectivity issues.

* RJ11 (6P2C)

{% step %}
### Connect the cable

Connect one end of the cable on one half of the tester each.

<figure><img src="https://guide-images.cdn.ifixit.com/igi/DUtSJgFGB4RrODUI.medium" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
If you are testing jacks you can just connect them with a known good patch cable.
{% endhint %}

{% hint style="info" %}
If the other side of your cable is already connected to a switch or some other device you can connect the **MASTER** device only.
{% endhint %}

{% hint style="danger" %}
Only do this with cable testers you trust, since crappy cable testers might not limit the current they send through the data lines.
{% endhint %}
{% endstep %}

{% step %}
### Switch on tester

Switch on the tester.

<figure><img src="https://guide-images.cdn.ifixit.com/igi/EfniQUjBsJCxXTEY.large" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
The tester has two modes: **ON** and **S**. There is no difference in the two modes besides the testing interval on **S** being more drawn out.
{% endhint %}
{% endstep %}

{% step %}
### Test the cable

The tester will go through all the wires in sequence. If the sequence of the green lights blinking does not line up you might have swapped some wires when wiring the connector.

<figure><img src="https://guide-images.cdn.ifixit.com/igi/tOQSCVgMWqaNnNjv.large" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
If some lights do not light up there might be a break in the cable or you made a mistake when crimping the connector.
{% endhint %}

{% hint style="info" %}
For Fast Ethernet (100 Mbit/s) you only need pins **1**, **2**, **3** and **6**. Some cheap cables may not even have more than these four wires.
{% endhint %}

{% hint style="info" %}
**G** means _ground_. For most consumer applications up to 1GbE it should be fine if your ground is not properly connected.
{% endhint %}
{% endstep %}

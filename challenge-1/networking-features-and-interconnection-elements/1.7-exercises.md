# 1.7 Exercises

#### Memory Measurements&#x20;

1. Given that one letter weighs a byte, how long would it take to transmit a document with 5,000,000 letters from one computer to another if our network was 20 Mbps?<br>
2. A file weighs 300,000 kB. How long would it take to transmit from one computer to another if our network was 120 Mbps?<br>
3. We have a 600MB (MegaByte) video file and we have to send it via our office's Fast Ethernet network that is 100Mbps. Fun fact is that the router is being fixed and the replacement is under 50 Mbps maximum speed rate. This seems to be a bottleneck. How long will it take?<br>
4. A 4GB (GigaByte) pixel file is sent from one computer to another from our school's 1Gbps speed network. How long will it take?<br>
5. In a store, we bought a 6 TB (TeraByte) built-in disc for gamer pc. When you get home and install the disk on the computer, the system detects that it has a lower capacity than specified in the specifications. How much is the loss? Do the TB and TiB calculations for that capacity and tell us how many GB we've been cheated.

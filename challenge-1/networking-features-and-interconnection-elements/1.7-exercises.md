# 1.7 Exercises

#### Memory Measurements&#x20;

1. Given that one letter weighs a byte, how long would it take to transmit a document with 5,000,000 letters from one computer to another if our network was 20 Mbps?<br>
2. A file weighs 300,000 kB. How long would it take to transmit from one computer to another if our network was 120 Mbps?<br>
3.  600MB(MegaByte)-ko bideo bat daukagu eta gure bulegoko 100Mbps-ra doan Fast Etherneteko saretik ordenagailu batetik betera bidali behar dugu. Zenbat denbora beharko da?


4.  4GB(GigaByte)-ko pixua daukan fitxategi bat, gure eskolako 1Gbps abiadura duen saretik bidali nahi da ordenagailu batetik bestera. Zenbat denbora beharko da?


5. Denda batean 6 TB (TeraByte)-eko diskoa eransgarria erosi dugu gamer pcerako. Etxera iritsi eta diskoa ekipoan instalatzean espezifikazioetan adierazia baino edukiera txikiagoa duela detektatu du sistemak. Zenbatekoa da galera? TB eta TiB kalkuluak egin edukiera horri dagozkonak eta esan zenbat GB timatu dizkiguten.
